# 运动数据生成

为 Keep 生成 FIT / TCX 运动数据文件的 Android 应用。

## 这是什么

选好场地和距离，生成一个标准的运动数据文件，然后导入 Keep。
支持田径场（标准 400m / 200m 跑道，按真实弧线跑）和自定义路线。

## 功能

- 田径场模式：内置安宁校区坐标，按真实跑道几何生成轨迹
- 自定义路线：粘贴高德链接、从路线库选、或用邀请码取别人的路线
- 输出 FIT 或 TCX，两者都能被 Keep 识别
- 可附带心率数据（仅 FIT）
- 生成后自动打开 Keep 并导航到导入页（需开启无障碍权限）

## 下载

到 [Releases](../../releases) 下载最新的 APK。

系统要求：Android 5.0（API 21）及以上。

## 使用说明

1. 装好后直接打开，选场地和距离
2. 点「生成」，文件保存到手机的 Download 文件夹
3. 点「自动导入 Keep」，应用会代你点到导入页
4. 在文件选择器里选中刚生成的文件

无障碍权限只用来点击 Keep 的菜单，不会读取或上传任何内容。
